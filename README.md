# 🎛️ Electronic Simulator

A simple interactive tool to calculate **resistor values and tolerance** based on color codes.  
This personal project demonstrates interactive calculation of resistor parameters.

---

## 🚀 Features
- Calculates resistor values from color codes  
- Calculates tolerance  
- User-friendly and responsive interface  

---

## ▶️ How to Run Locally
**cd simulation**  
**npm install**  
**npm run dev**  

👉 Open [http://localhost:3000/Electronics](http://localhost:3000/Electronics) in your browser.
